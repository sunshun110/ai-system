# Workflow: Grill Me

Use when a request is too ambiguous to implement safely.

## Goal

Turn a fuzzy idea into a decided implementation plan.

## Rules

- Ask one question at a time.
- Give a recommended answer with reasoning.
- Do not ask questions that local code can answer.
- Do not ask about rules already decided by the project.

## Process

1. Load relevant rules and context.
2. List unresolved decisions privately.
3. Separate decisions into:
   - already decided by rules
   - discoverable from code
   - requiring user judgment
4. Ask the next highest-impact question.
5. Track confirmed decisions.
6. Exit with a concrete plan.
