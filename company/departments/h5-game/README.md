# H5 游戏部门

这是公司当前的第一个业务部门，负责浏览器运行的 H5 游戏。策划、程序、测试和运维架构师岗位由 `../../roles/` 共享，本目录只保存所有 H5 游戏共同遵守的制作流程和交付标准。正式视觉制作暂不属于当前流程。

## 目录

- `workflows/`：新项目启动和完整游戏制作流程。
- `standards/`：Figma 原型与 H5 技术交付规范。
- `templates/`：新游戏项目的最小开项资料和项目规则模板。

公司共享岗位、组织改进规则和组织状态分别位于 `../../roles/`、`../../workflows/组织改进.md` 和 `../../handoff.md`。

## 使用方式

在工作区根目录打开 Codex，并明确目标游戏项目。AI 先读取项目规则，再通过 `../../AGENTS.md` 进入公司和本部门。

新项目不复制公司岗位、部门流程或标准。只使用 `templates/` 创建项目自己的开项文档和精简 `AGENTS.md`，随后由共享岗位按 H5 部门流程产出项目文件。
