# 公司

这里是 AI System 内的公司组织层。公司只有一套共享岗位，通过不同部门承接不同业务线，让相同岗位的经验可以跨部门积累。

## 当前结构

```text
company/
├── roles/                  # 策划、程序、测试、运维架构师的共享能力
├── workflows/              # 跨部门组织流程
└── departments/
    └── h5-game/            # H5 游戏部门专属流程、标准和模板
```

当前只有 H5 游戏部门。未来新增网站、Unity 或其他业务时，在 `departments/` 下建立新部门，优先复用 `roles/` 中的岗位，只补充该部门确实不同的工具、流程和交付标准。

## 使用入口

项目先读取自己的规则，再统一进入 `company/AGENTS.md`。公司入口负责选择部门和共享岗位，项目不需要在多个公司目录之间跳转。

项目经验先进入工作区独立复盘库；单部门改进写回部门，跨部门改进写回共享岗位或公司流程。
